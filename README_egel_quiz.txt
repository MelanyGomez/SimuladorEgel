QUIZ EGEL-ISOFT

1. Instala Python 3 si no lo tienes.
2. Abre CMD en esta carpeta.
3. Instala la dependencia:
   pip install pymupdf
4. Ejecuta:
   python egel_quiz_gui.py "EGEL INGENIERIA DE SOFTWARE 2021-1.pdf"

También puedes ejecutar sin pasar el PDF y el programa te pedirá seleccionarlo:
   python egel_quiz_gui.py

Modos:
- Primera práctica: 100
- Segunda práctica: 100
- Tercera práctica: 100
- Cuarta práctica: 100
- Todas: 400
- Aleatorio: 40

Las respuestas se obtienen del apartado de respuestas del mismo PDF.
El PDF tiene un reactivo de la cuarta práctica cuyo enunciado no aparece en la extracción de texto; el programa lo conserva para no perder la numeración y sus opciones.
